Personal / Portfolio Demo Project

Finance Dashboard

Personal finance dashboard for budgeting, expenses, savings, income and financial planning, with interactive charts.

Problem

Personal budgets and expenses are easy to lose track of when income, spending and savings all live in separate, disconnected records.

Objective

Build a single Excel dashboard to track income, expenses and savings together, making it easy to see spending patterns and plan ahead.

Approach

  • Organized income, expense and savings data into a structured model
  • Built Pivot Tables to break spending down by category and month
  • Applied Excel formulas to automate budget vs. actual calculations
  • Designed clear charts and KPI cards for quick financial snapshots

What I Built

An interactive Finance Dashboard covering budgeting, expense tracking, savings progress and income overview — shown in the video walkthrough above.

Key Insights

Category-level breakdowns made it easy to spot which spending areas were over budget, and month-over-month charts made saving trends immediately visible without manual recalculation.

Outcome

A reusable personal-finance dashboard template that demonstrates practical budgeting and financial-analysis skills applied to everyday data.

Tools Used

Microsoft Excel Financial Analysis Pivot Tables Charts & KPIs
