How this works: This dashboard runs entirely in your browser. There is no backend, no database and no login — edits are saved as a local draft in this browser only (via localStorage), never to the live site automatically. To publish changes, edit a project/skill/tool/setting, then use the Download button for that section and replace the matching file in your GitHub repo (data/projects.json, data/skills.json, data/tools.json, or assets/js/config.js), then commit & push. This page is not linked from the public site and is excluded from search engines, but it is not password-protected — anyone with this URL can open and edit a local draft here, though they cannot change your live site without commit access to your repository.

GitHub Pages can't scan your file system from the browser, so there's no separate media database. This list is a live view of every image and video already referenced by a project. To add new media, upload the file to your repo (e.g. assets/images/ or assets/videos/) and set its path in that project's Image/Video field in the Projects tab — it will appear here automatically.

Statistics

These are computed live from your current project data — never invented numbers. For true visitor analytics (visits, sessions, traffic sources) see the Analytics tab and your GA4 dashboard.

Analytics

Full visitor analytics (users, sessions, traffic sources, devices, top pages) live inside Google Analytics 4 once configured — a static GitHub Pages site cannot safely query the GA4 Reporting API from the browser, because that requires a private service-account credential that must never be exposed in frontend code. View your real numbers directly: analytics.google.com ↗. A secure backend/API proxy would be the correct way to pull GA4 numbers into this dashboard in the future — this admin panel is structured so that could be added later without changing anything else.
